Install MicroPython

Connect your board over USB. Close any serial monitor before installing. Installation replaces the program and files on the board.

Matrix:bit

For the classic ESP32 version with 8 MB flash. Installs official ESP32_GENERIC MicroPython firmware.

BBC Micro:bit

Installs the Micro:bit Educational Foundation firmware for V1 or V2. The USB connection identifies the board version.

Download V1 HEX Download V2 HEX

To install manually, copy the HEX for your version to the MICROBIT drive.
