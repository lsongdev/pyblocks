# Documentation screenshots

These images were captured from the real English PyBlocks interface in a separate in-app browser tab at 1280 × 720. Only the public beginner examples were loaded; no personal browsing or real credentials are included. Disconnected controls are shown as disconnected, without fabricated output.

Only WebP copies are committed. The original JPEG captures were converted with `cwebp -q 85 -m 6 -sharp_yuv`. Keep future captures at a modest viewport size and check that block labels remain readable after compression.
